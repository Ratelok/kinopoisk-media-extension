# Kinopoisk MediaStack Integration (Firefox Extension)

Расширение для Mozilla Firefox, которое интегрирует сайт **Кинопоиск** с вашим домашним медиастеком (**Jellyseerr / Overseerr** и **Jellyfin**).

Виджет органично встраивается в страницу любого фильма или сериала, полностью повторяя визуальный стиль Кинопоиска, отображает текущий статус в медиатеке и позволяет в один клик отправить фильм на скачивание или сразу начать просмотр.

---

## 🌟 Возможности

- **Эстетичный нативный дизайн**: Кнопки и бейджи выполнены с соблюдением цветовой палитры, скруглений (12px) и типографики Кинопоиска.
- **Интерактивные статусы**:
  - `[ 📥 Скачать ]` — тайтла нет в стеке, клик отправляет запрос в Jellyseerr.
  - `[ ⏳ Отправка... ]` — индикатор обработки сетевого запроса.
  - `[ 🕒 Запрошен ]` — фильм уже ожидает одобрения/загрузки.
  - `[ ⏬ Качается: 48% ]` — отображение реального прогресса загрузки торрента клиентом.
  - `[ ✓ В медиатеке ]` — подтверждение наличия тайтла в домашней библиотеке.
  - `[ ▶ Смотреть в Jellyfin ]` — прямая ссылка на карточку фильма/сериала в веб-плеере Jellyfin.
- **Поддержка SPA-навигации**: Переходы между фильмами и сериалами на Кинопоиске отслеживаются без необходимости обновлять страницу.
- **Универсальность для любого пользователя**: Любой человек может открыть настройки расширения, ввести адрес своего сервера (домен или IP) и API-ключ.
- **Защита от CORS и блокировок**: Все сетевые запросы к домашнему серверу выполняет фоновый сервис-воркер (`background.js`), не подверженный ограничениям CSP Кинопоиска.
- **Умное кэширование**: Статусы кэшируются настраиваемое время (по умолчанию 60 секунд), чтобы не создавать избыточную нагрузку на домашний сервер.

## 🚀 Установка в Firefox

### Способ 1: Быстрая установка (Режим разработки)

1. Откройте браузер Firefox и перейдите по адресу:
   ```text
   about:debugging#/runtime/this-firefox
   ```
2. Нажмите кнопку **«Загрузить временное дополнение…»** (*Load Temporary Add-on…*).
3. В открывшемся окне перейдите в папку:
   ```text
   apps/kinopoisk-media-extension/
   ```
4. Выберите файл `manifest.json` (или готовый архив `dist/kinopoisk-mediastack.zip`).
5. Расширение загрузится и его иконка появится в панели инструментов Firefox!

### Способ 2: Установка готового `.xpi` (Firefox Developer Edition / Nightly)

В версиях Firefox Developer Edition или Nightly можно отключить проверку подписи в `about:config`:
`xpinstall.signatures.required` -> `false`, после чего просто перетащить файл `dist/kinopoisk-mediastack.xpi` в окно браузера.

## ⚙️ Настройка расширения

После установки нажмите правой кнопкой мыши по иконке расширения и выберите **«Настройки»** (или кликните по иконке шестеренки во всплывающем окне):

1. **Jellyseerr / Overseerr**:
   - **URL сервера**: Укажите полный адрес (например, `https://requests.ratelok.xyz` или локальный `http://192.168.31.63:5055`).
   - **API Ключ**: Скопируйте ключ из интерфейса Jellyseerr:
     *Настройки (Settings) → Общие (General) → API Key*.
   - Нажмите **«Проверить Jellyseerr»** — должна появиться зеленая галочка с версией сервера.
2. **Jellyfin**:
   - **URL сервера**: Укажите адрес плеера (например, `https://jellyfin.ratelok.xyz` или `http://192.168.31.63:8096`).
   - **API Ключ (опционально)**: Токен из *Панель управления Jellyfin → Ключи API*. Нужен в случае, если тайтл еще не успел связаться внутри базы Jellyseerr.
   - Нажмите **«Проверить Jellyfin»**.
3. Нажмите кнопку **«Сохранить настройки»**.

## 📂 Структура файлов

```text
apps/kinopoisk-media-extension/
├── manifest.json              # Манифест WebExtension (MV3)
├── background/
│   ├── background.js          # Маршрутизатор сообщений, кэширование и координация
│   ├── jellyseerr-api.js      # Клиент API Jellyseerr (поиск, запрос, расчет прогресса)
│   └── jellyfin-api.js        # Клиент API Jellyfin (генерация ссылок и fallback-поиск)
├── content/
│   ├── content.js             # Парсинг метаданных Кинопоиска, SPA-наблюдатель, инжекция UI
│   └── content.css            # Фирменная стилизация кнопок в дизайне Кинопоиска
├── options/
│   ├── options.html           # Страница настроек расширения
│   ├── options.css            # Темная стилизация панели настроек
│   └── options.js             # Валидация, тест соединений и сохранение в storage
├── popup/
│   ├── popup.html             # Всплывающее меню по клику на значок в панели
│   ├── popup.css              # Компактная карточка фильма
│   └── popup.js               # Быстрый статус текущей вкладки и ссылки на сервисы
├── icons/                     # Иконки (16, 32, 48, 128 px + SVG)
├── test/
│   └── run-tests.js           # Автоматические тесты парсинга и API
├── dist/                      # Собранные архивы .zip и .xpi
├── package.json               # Скрипты сборки и тестирования
└── README.md                  # Документация проекта
```

---

## 🛠️ Сборка и тестирование

Запуск встроенных тестов проверки манифеста, синтаксиса и алгоритмов парсинга:
```bash
npm test
```

Сборка готовых пакетов для распространения:
```bash
npm run package    # создает dist/kinopoisk-mediastack.zip
npm run build:xpi  # создает dist/kinopoisk-mediastack.xpi
```
